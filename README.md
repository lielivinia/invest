# 🤖 Personal AI Investment Assistant Web App

A clean, interactive data dashboard built in Python that fetches real-time financial metrics from Yahoo Finance and uses free AI logic to provide structural buy, hold, or sell insights.

## 🚀 Features
- **Real-Time Data Extraction:** Automatically pulls historical prices for SGX and US tickers.
- **Quantitative Metrics:** Calculates 14-day RSI and 20/50-day Simple Moving Averages (SMA).
- **AI-Powered Analytics:** Provides dynamic strategy recommendations based on custom risk profiles.

## 📦 Installation & Setup

1. **Clone or download this repository to your local machine.**
2. **Install all software dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## 🛠️ How to Launch the Web App
Run the following execution command in your terminal to start the local server:
```bash
streamlit run app.py
```
The application will automatically open in your web browser at `http://localhost:8501`.
